# NexusWST

Carpeta destinada al desarrollo del proyecto de programación del Capstone: modernización de la plataforma logística de WeStorage, pasando de un sistema monolítico acoplado a una solución en la nube.

## Alcance

- Control de inventario y stock comprometido.
- Gestión de órdenes: ingreso, validación, asignación a olas, empaque y entrega al courier.
- Visibilidad del despacho para operaciones y clientes.

## Tecnologías

Go (servicio Core y servicio de Órdenes), Next.js/React, PostgreSQL, Redis, Traefik y Docker Compose.

## Organización

Esta carpeta contiene solo lo relacionado con el desarrollo del proyecto. Las actividades y entregas académicas están en `Actividades Capstone_003D/`.
